# TwiXP

Twitch-чат для Windows XP. Нативное приложение без браузерного движка,
рассчитанное на слабое железо (ориентир — Eee PC 701, Celeron ULV
~630 МГц): свой рендер текста, минимум зависимостей, экономия процессора
и памяти.

Написано на Go 1.10.8 с GUI на [lxn/walk](https://github.com/lxn/walk).

## Что умеет

- Вход по коду: показывает код, подтверждаете на телефоне или другом
  компьютере. Пароль не нужен.
- Несколько каналов сразу, у каждого своя история.
- Отправка сообщений и ответы.
- Бейджи с иконками, аватарки каналов.
- Подсветка сообщений, где вас упомянули, и автодополнение `@ников`.
- Уведомления о подписках, рейдах и объявлениях; пометка сообщений за
  баллы канала; серые удалённые сообщения.
- Плашки режимов чата: только смайлики, только подписчики, только
  фолловеры, медленный режим, только уникальные сообщения.
- Сворачивание в трей по крестику.
- Настройки (время, бейджи, аватарки, подсветка, размер шрифта, окно
  поверх всех) применяются сразу, без перезапуска.
- Переподключение при обрыве сети.

## Сборка

Нужен Twitch Client ID: зарегистрируйте приложение на
[dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps)
(client secret не нужен), затем:

```sh
cp config.go.example config.go   # впишите свой Client ID в clientID
make deps                        # один раз: стянуть lxn/walk и остальное
make check                       # быстрая проверка компиляции
make build                       # финальная сборка → bin/twixp.exe
```

`make build` использует настоящий Go 1.10.8 (путь можно задать через
`make build GO_XP=/путь/до/go1.10.8`):

```sh
go install golang.org/dl/go1.10.8@latest
go1.10.8 download
```

`make check` собирает обычным Go под Windows. Он годится для проверки
компиляции, но не заменяет `make build`: Go 1.10.8 может не принять то,
что новый Go пропускает.

Проверки кода без Windows (их же гоняет CI на каждый push):

```sh
make vet-core   # go vet
make test       # go test
make fmt        # список неотформатированных файлов
```

## Где лежат данные

В профиле пользователя, `%APPDATA%\TwiXP`:

```
state.json  настройки и список каналов
token.bin   токен входа, зашифрованный Windows DPAPI
cache\      кэш аватарок и иконок бейджей (до 20 МБ)
twixp.log   журнал
```

Кэш можно удалить в любой момент, картинки скачаются заново.

## Структура

```
internal/domain   типы данных
internal/app      сценарии: вход, чат, список каналов
internal/infra    Twitch API, хранилище, кэш картинок
internal/ui       окно и отрисовка
```

Зависимости идут только в одну сторону: `ui` → `app` → `domain`,
`infra` реализует интерфейсы из `app`.
